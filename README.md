# PASTOR ABAYOMI BIBLE STORIES — Kids Bible v1.4
Colourful child-friendly web/PWA Bible reader.

Includes five public-domain English Bible versions: KJV, WEB, ASV, Geneva Bible 1599 and Douay-Rheims. Features Bible books, chapter reader, search, bookmarks, notes, daily verse, child-friendly visual navigation and installable PWA support.
